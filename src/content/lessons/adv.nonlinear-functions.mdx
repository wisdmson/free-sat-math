## Read a quadratic rule

In vertex form, <M t="f(x)=a(x-h)^2+k" />, the vertex is <M t="(h,k)" />. If <M t="a>0" />, the graph opens up and has a minimum; if <M t="a<0" />, it opens down and has a maximum. Function notation still means substitute the input everywhere <M t="x" /> appears.

## Exponential patterns

An exponential model often has the form <M t="A(1+r)^t" /> for growth or <M t="A(1-r)^t" /> for decay. The starting amount is <M t="A" />; the percent change is applied repeatedly, so it is not the same as adding a fixed amount each step.

## Common traps

- Reading the vertex's x-coordinate as its minimum or maximum output.
- Treating <M t="(x-h)^2" /> as <M t="x^2-h" />.
- Adding a repeated percent change instead of multiplying by the growth factor each period.
