## Solve like an equation

Use the same inverse operations as for an equation. Keep the inequality sign pointing the same way when adding, subtracting, or multiplying by a positive number. **Reverse the sign** when multiplying or dividing by a negative number.

## Describe the whole solution set

An inequality usually has many solutions. For example, <M t="x<4" /> includes every number below 4. On a number line, use an open circle at 4 because 4 is excluded, then shade left. For <M t="x\le4" />, use a closed circle.

## Common traps

- Forgetting to reverse the inequality after dividing by a negative.
- Giving only one value when the question asks for a range.
- Treating <M t="<" /> and <M t="\le" /> as if they include the same endpoint.

## Desmos steps

1. Enter `y=3x+2` and `y=14` to see the boundary where the two sides are equal.
2. Enter the inequality, such as `3x+2<14`; Desmos shades the solution region on the number line.
3. Check whether the boundary itself is included before reporting an endpoint.
