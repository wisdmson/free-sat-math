## What the rule tells you

In <M t="f(x)=mx+b" />, <M t="m" /> is the change in output for each 1-unit increase in input. The value <M t="b" /> is the output when the input is 0. To evaluate the function, replace every <M t="x" /> with the given input, then calculate.

## Build or compare lines

Given two points, calculate slope with <M t="(y_2-y_1)/(x_2-x_1)" />. Then use either point in <M t="y=mx+b" /> to find the intercept. A table with a constant rate of change describes a linear function.

## Common traps

- Swapping the x- and y-coordinates when finding slope.
- Treating the intercept as the slope.
- Forgetting that a function's input is substituted everywhere <M t="x" /> appears.

## Desmos steps

1. Enter the rule, for example `f(x)=3x+2`.
2. Enter `f(5)` on a new line to evaluate it, or type `(5,f(5))` to mark the point.
3. Change the input and observe how the output changes by the slope each time.
